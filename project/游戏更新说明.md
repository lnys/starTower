- 调整 4、8、14–19、22、25、28 层黄门，校正第 39 层蓝药及第 48 层蓝药和蓝钥匙，补回第 41 层裂墙；全塔裂墙为 10 处。已生成过的楼层沿用存档里的地图与拾取状态。
- 修复 README 微信群二维码图片链接，扩大网页游戏二维码留白。两张二维码均可解码。
- Vue 和 Flutter 从新游戏逐步通关：3779 步，生命 1241、攻击 378、防御 501。Vue 28 项引擎、17 项规则和地图校验通过；Flutter 静态检查和 20 项测试通过。其余验证范围见 [通关测试](通关测试.md)。

## v1.0.3 — 2026-11-18

本版更新可复用 Skill 与游戏源码，不新增各平台安装包；现有客户端下载仍对应此前发布版本。

## 本次更新概览

- NPC 与怪物改用图标，修复快速存档文字折行。
- 加入拯救女神的主线、通关惊喜页，重做第 50 层小屋、守卫和巨型女妖场景。
- Flutter Web / PC 改为按屏幕比例显示，NPC 对话、交易与普通消息移到棋盘下方。

## 图标与操作界面

- 引路人、祭坛和全部 38 种怪物均有 SVG 图标，后半程不再以单个汉字代替 NPC 或怪物。
- Vue 与 Flutter 共用图标映射；地图和素材经 `node flutter/tool/export-vue.mjs` 同步至 Flutter。
- 修复“快速存档”折行，Flutter 缩小按钮横向内边距并固定单行，Vue 按钮禁止换行。
- 调整 Flutter 顶部区域名称的收缩方式，兼顾窄屏显示。

## 拯救女神的故事与结局

- 登塔目的统一为解救被终焉女妖囚禁在第五十层的女神，开场对白与网页介绍同步更新。
- 通关后展示女神插画、星光动画、可拆开的信件、纪念称号“她的唯一勇者”及本局数据。
- 已通关存档读取后可重看结局、拆信并返回标题，无需再次击败首领。
- Flutter 结局页支持小屏滚动，并适配减少动态效果的系统设置。

## 第五十层：星空花园与月光小屋

- 中央月光小屋内安置女神，四名可战斗的星柱守卫分布于四周。
- 小屋前由巨型终焉女妖把守；巨角、残翼、獠牙、猩红双眼与胸前裂隙形成暗黑轮廓。
- 女妖横向显示约 2.5 格、高约 2.2 格，图层不截获点击，勇者保持在前景。
- 新增星空、月牙屋顶、花圃、水晶喷泉、灯笼与长毯。女神为 NPC，不能被当成道具拾取。
- 击败终焉女妖即解除封印、营救成功并进入惊喜结局，不要求额外清空四名守卫。
- 首领战斗数值保持不变；星幕防御仍由第 49 层的存活星柱守卫决定，第 50 层新增守卫不影响星幕。

## 存档兼容

- 第 50 层场景使用 `sceneVersion: 2`。已有终层存档加载后升级场景，保留人物属性、装备、钥匙、首领击败状态和通关状态。
- 场景只迁移一次，后续读取不重复生成已击败守卫；已通关存档不会复活女妖。
- 不改写玩家磁盘存档来证明通关，测试使用独立构造状态及真实引擎回放。

## Flutter 窗口与提示区（2026-11-18）

- Mac / Windows 桌面窗口按当前屏幕宽度的 1/4、高度的 4/5 打开，水平居中，上下各留屏幕高度的 1/10；关闭手动调整尺寸、最大化。移动端原生布局继续适配手机。
- Web 游戏区域使用浏览器可视区域宽度的 1/4、高度的 4/5，水平居中，上下各留 1/10；拦截常用页面缩放手势和快捷键。网页无法锁定浏览器外框或系统级缩放。
- NPC 对话、祭坛 / 商人交易和战斗 / 拾取提示统一在棋盘下方的固定区域展示。长内容内部滚动，底部方向键与菜单保持独立可操作。
- 窄窗口下自动适配游戏布局，NPC 长对白和交易列表在提示区内滚动；移动期间仍可使用方向键。
