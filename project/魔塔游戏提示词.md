# 魔塔游戏开发提示词（给 Fable 5.2）

> 使用方式：将下方「提示词正文」整体粘贴给 Fable 5.2 即可。正文之外的内容是给你看的说明，不需要发送。
> 版本：2026-11-13 合并版。已包含之前所有的修改需求，并以当前实际实现为准。

---

## 提示词正文

你是一位资深的独立游戏开发者兼像素美术设计师，擅长用 Vue 3 做出精致、流畅、有品质感的小游戏。请为我开发一款完整的**魔塔（Magic Tower / Mota）风格 RPG 游戏**。目标是做出一部可以让玩家沉浸数小时的"大作"级作品，既要有完整的内容，也要在手机和电脑上都有精致的界面。

### 一、交付形式（硬性要求）

1. **技术栈（Vue 3 优先）**：使用 **Vue 3**（Composition API）+ **Vite**。游戏核心逻辑（伤害计算、地图、存档、剧情推进）保持为与 Vue 解耦的纯 JS 模块，Vue 组件只负责渲染与交互。
   - 运行方式：`npm install` 后 `npm run dev` 开发，`npm run build` 生成 `dist/`。
   - 双击打开：`vite.config.js` 中设置 `base: './'`，并使用 `vite-plugin-singlefile` 把产物打成单个 `dist/index.html`，可直接双击打开。
   - 不依赖后端服务。
2. **代码结构**：
   ```
   mota/
   ├── index.html
   ├── package.json
   ├── vite.config.js
   ├── images/                 # 【所有图片素材统一放这里】
   │   ├── tiles/              # 墙、地面、门、楼梯、商人等图块（按楼层主题分套）
   │   ├── monsters/           # 怪物与 Boss（mon_1 … mon_V）
   │   ├── items/              # 钥匙、血瓶、宝石、圣剑、盾牌、卷轴、星辰碎片
   │   ├── hero/               # 勇士
   │   ├── ui/                 # 图标（血量、攻击、防御、金币、经验等）
   │   └── bg/                 # 标题背景
   ├── scripts/
   │   └── generate-images.js  # 用代码批量生成 SVG 素材，脚本与输出都要保留
   ├── src/
   │   ├── main.js             # Vue 入口（含禁止缩放的事件拦截）
   │   ├── App.vue             # 根组件：电脑端模拟器布局 / 手机全屏，键盘与手势
   │   ├── components/         # 标题页、游戏页、地图、顶栏与信息栏、方向键、弹窗、剧情框、结局特效、电脑端介绍
   │   ├── stores/game.js      # 应用状态与动作（移动、战斗、存档、隐藏模式）
   │   ├── engine/             # 音频（Web Audio）、本地存储、素材索引、按住连续移动
   │   ├── game/               # 纯逻辑：core.js（战斗、移动、存档修复）、data.js（楼层、怪物、道具、剧情）
   │   └── styles/main.css     # 全局主题变量
   ├── tests/run.js            # node tests/run.js 运行全部测试
   └── README.md               # 运行方式、操作说明、项目结构、已知问题
   ```
3. **数据与逻辑分离**：楼层地图、怪物、道具、剧情都放在 `src/game/data.js`，新增一层或一个怪物不应需要改动核心逻辑。
4. 所有代码、注释、界面文字使用**简体中文**。
5. **禁止缩放**：页面 viewport 设为不可缩放，并拦截双指捏合和双击放大（含 iOS Safari）。

### 二、视觉与美术

目标风格：**精致的暗色奇幻风**，有复古像素的趣味，也有现代 UI 的质感。

1. **画面与素材**
   - 所有图片素材都是 `images/` 下的真实 SVG 文件，由 `scripts/generate-images.js` 生成，代码中通过相对键名引用，不写成 base64 常量。
   - 地面**不能有条纹或生硬的网格线**，用柔和的明暗斑块；墙的每块砖明暗略有不同，不能出现整行一致的横向条纹。
   - 楼层主题分套配色：第 1–5 层石砖地牢、第 6–8 层幽暗苔林、第 9 层熔岩火狱、第 10 层深渊王座、第 11–15 层冰封深渊、第 16–20 层虚空回廊。切换楼层时有过渡动画。
   - 怪物有待机微动，Boss 有呼吸发光；勇士周围有柔和光圈。
2. **动效与反馈**
   - 勇士移动为平滑的格间缓动，不是瞬移。
   - 怪物受击时震动，伤害数字、金币、经验用飘字，颜色区分（伤害红、回血绿、金币黄、经验蓝）。
   - 开门、拾取、升级、击败 Boss 都有明确的反馈动画。
   - 剧情文字逐字打出（打字机效果），可点击或按键看完本句；提供"跳过全部"按钮，点击后直接关闭剧情，不再弹出后续提示。
   - **通关特效**：结局弹出时有旋转光芒、闪光、连续绽放的烟花和慢慢落下的星光；隐藏结局用紫蓝色调，普通结局用金色。结局标题有入场动画。系统开启"减少动态效果"时只保留静态光芒。
3. **界面布局（手机，单屏）**：整个游戏界面在一屏内完成，不滚动，从上到下依次是：
   - **顶栏**：左侧是楼层（大号数字，"第 N 层" 与楼层名称，要突出）；右上角是金币。**左上角不放菜单按钮**。
   - **角色信息区**（一块统一面板，高度尽量小，把空间让给地图）：
     - 第一行：灰色小字"生命" + 生命条用**红色**，中间显示"当前 / 上限"数字；无敌时右侧显示金色"无敌"标识。（等级不单独显示）
     - 第二行：经验细条。
     - 第三行：四格属性——攻击、防御、卷轴（有数量）、星辰碎片（三颗星图标，已收集的亮起，未收集的灰色，右侧 "n/3"）。
     - 第四行：三格钥匙——黄、蓝、红钥匙各带钥匙图标，显示完整中文名称与数量。
   - **地图**：占据中间主要区域，格子大小按宽度取最大值；地图与上下区域之间各留约 20px 间距；属性与钥匙字号小于生命数值；多出的高度交给方向键（方向键变大）。顶栏楼层只显示「第 N 层」与副标题，不重复楼层名。
   - **操作区**：左边是方向键（按住可连续移动），右边是功能按钮：**菜单（整行，突出显示，放在最上方）**、卷轴、图鉴、存档、设置。
4. **界面布局（电脑端）**：宽屏（≥700px 且鼠标操作）时：
   - 左侧（整体居中，靠左放置）是 iPhone 模拟器外壳，里面就是可以直接操作的手机游戏界面；外壳按屏幕高度等比缩放，最高 980px，宽高比 393:852。
   - 右侧（与模拟器一起整体居中）是介绍面板，**整页只显示一屏，不出现滚动条**：
     - 大标题"魔塔"（渐变金色，字号随屏幕高度变化），英文副标题，一句简介。
     - 游戏简介、通关路线（1–4 层、5 层、10 层、15 层、20 层及其 Boss）。
     - 核心玩法（直接战斗、钥匙与门、商人与补给、Boss 战、星辰碎片、成长）。
     - 攻略小贴士、操作说明、难度与结局，三列并排。
     - **底部是扫码二维码**（横向卡片，二维码在左、说明在右）。二维码指向页面所在的网址；本地打开时显示占位。
   - 屏幕较矮时（高度 ≤ 760px）隐藏"游戏简介"、"通关路线"和标题下的简介，保证仍然一屏显示二维码。
   - 手机和平板访问时不显示外壳和介绍，直接全屏。
5. **UI 设计语言**：深色半透明面板、细边框、圆角、金色点缀，字体使用 Google Fonts 中的中文字体（Noto Sans SC、ZCOOL XiaoWei）并带系统回退。颜色统一定义为 CSS 变量。
6. **标题页**：有标题动画和背景粒子，菜单包括：新的冒险、继续冒险、读取存档、图鉴、设置、操作说明。背景音乐在第一次点击屏幕后开始。

### 三、音频

1. 使用 Web Audio API **程序化生成**音效（移动、开门、拾取、攻击、受伤、升级、死亡、胜利、购买），并提供音量与静音开关（按 M 键静音）。不依赖外部音频文件。
2. **音量**：默认 90%，音效与背景音乐整体放大，并加压缩器防止爆音。
3. **背景音乐**：
   - 标题画面有一首舒缓的背景音乐。
   - **每一层都有自己的背景音乐**：调式、主音、节奏由层数决定，相邻层不得听起来一样。
   - Boss 层使用更快、更紧张的专属版本，并在进入 Boss 层时切换。切换楼层时平滑切换，不叠加播放。
4. **手机播放**：浏览器（尤其 iPhone Safari）要求用户手势才能出声，任意一次点击、触摸或按键都要解锁音频并播放标题音乐。iPhone 上声明为"播放"类音频会话，开着静音键也能出声（iOS 16.4 及以上）。

### 四、游戏设定与剧情

- 世界观请**原创**：一座通天魔塔，共 20 层，每层由守卫怪物把守。勇士为了救出被困的妹妹而攀登，塔顶的虚空之主被击败后揭示结局。
- 剧情：开场序章、楼层介绍、第 5、10、15 层中 Boss 战前后的对白、终极 Boss 结局、隐藏结局。剧情文本在 `src/game/data.js` 中。
- **结局**：文字播完后先显示结算（抵达层数、等级、击败敌人、金币、星辰碎片），由玩家点击"返回标题"才回到主界面，不会自动跳转。
- **隐藏结局《星辰之约》**：收集全部 3 枚星辰碎片（第 2、6、9 层各 1 枚），且这一局没有使用无敌模式或跳转楼层，击败终极 Boss 时自动判定。

### 五、核心玩法规则（请严格实现）

**勇士初始属性**：等级 1，生命 1000，攻击 10，防御 10，金币 0，经验 0，黄/蓝/红钥匙各 0。

**升级**：经验达到阈值自动升级（阈值 = 20 × 当前等级），每级生命 +150、攻击 +4、防御 +4。

**战斗（回合制、自动结算，但有动画）**
- **走进怪物即直接战斗，不弹窗、不需要确认。**
- 勇士每回合伤害 `max(0, 勇士攻击 − 怪物防御)`，怪物每回合伤害 `max(0, 怪物攻击 − 勇士防御)`，勇士先出手。
- 回合数 `n = ceil(怪物生命 / 勇士伤害)`，勇士承受 `怪物每回合伤害 × (n − 1)`。
- Boss 每第 3 次反击造成双倍伤害。
- **无法破防**（勇士攻击不大于怪物防御）或**会死亡**（预计损失 ≥ 当前生命）时，**拒绝进入**，并给出提示。
- **怪物头顶的信息卡片**（与勇士相邻的怪物都显示）必须包含：
  - 怪物名称（大字）、生命 / 攻击 / 防御；
  - 结论：「可以击败」或「会死亡」或「无法破防」（绿色或红色边框）；
  - 我方每回合伤害与需要回合数，怪物每回合伤害；
  - 预计损失与战后剩余血量；
  - **需要血量至少 X**（X = 预计损失 + 1），并标明当前血量。
  - 卡片字号要足够大、清晰可读，不能出现文字重叠；第一行的怪物卡片显示在下方，靠边的怪物卡片贴边对齐，不被棋盘裁切。
- 战斗结束后，勇士获得怪物的金币与经验；击败怪物会在图鉴中记录。

**门与钥匙**
- 黄门、蓝门、红门分别需要对应颜色的钥匙，钥匙用完即消失。
- 钥匙不够时门不能开启，有明确提示（如"需要黄钥匙才能打开"）。
- 钥匙和星辰碎片在界面中分开显示；钥匙带图标与完整中文名称。

**道具**
- 小血瓶（回复 200）、大血瓶（回复 600）
- 攻击宝石（攻击 +5）、防御宝石（防御 +5）
- 圣剑（攻击 +15）、盾牌（防御 +15）
- 清怪卷轴：清除当前楼层的普通怪物，不含 Boss，不给奖励，按 Z 或点击卷轴按钮使用。
- 星辰碎片：隐藏收集物，3 枚用于隐藏结局。
- 黄、蓝、红钥匙。

**楼层与探索**
- 共 **20 层**，每层 11×11 的网格地图，书写时省略底部外墙，程序补齐。
- 每层有上楼梯 `^` 和下楼梯 `v`，首层的 `v` 是入口；最后一层没有上楼梯。
- **楼梯旁边不放怪物**：上楼梯 `^` 与下楼梯 `v`（含斜角）周围一格内不能有怪物（测试检查）。
- **前三层单路**：第 1–3 层各是一条唯一的通路（从入口到上楼梯没有分叉，只有尽头的口袋里放道具、钥匙与商人），路上有一只怪物堵路，不打怪就上不了楼（测试检查）。第 4 层起允许部分楼层不打怪直接上楼，只要拿到钥匙即可。
- **不能跳层**：除第 1 层（教学层）外，每层的上楼梯都必须由一扇门挡住，玩家必须在本层找到对应钥匙，才能上楼。这一条要有自动化测试检查。
- **最后一层（第 20 层）没有上楼梯**，击败终极 Boss 即为通关；进入时给出明确提示（"这是最后一层：击败虚空之主即可通关"）。
- 每层都必须有解：从入口出发，在不死亡的前提下正确使用钥匙和探索，就能到达上楼梯。测试要检查这一点。
- 地图使用字符矩阵（图例见 `data.js` 中的 LEGEND），例如 `#` 墙、`.` 地板、`Y/B/R` 黄/蓝/红门、`y/b/r` 钥匙、`^` 上楼梯、`v` 入口、`N` 商人、`G` 星辰碎片、`1–9`、`C–V` 怪物。

**中 Boss 与终极 Boss**
- 第 5 层：骷髅王（小 Boss，不是必经之路）。
- 第 10 层：深渊领主（中 Boss）。**本层的上楼梯被封印**：击败深渊领主之前，楼梯隐藏成墙壁，无法通过；击败后楼梯显现，并给出提示。本层王座旁有一瓶大血瓶，供战前补给。**深渊领主有 80% 封锁**：必须先击杀第 3–9 层至少 80% 的怪物（约 16 只中需击杀 13 只），才允许与它战斗；未满足时头顶卡片显示"尚未解锁"并说明还差多少只。第 3–9 层保留部分怪物，允许跳过，但击杀比例会影响能否挑战领主。
- 第 15 层：霜魔王（中 Boss）。
- 第 20 层：虚空之主（终极 Boss，击败即通关）。
- Boss 有专属技能（每第 3 次反击双倍伤害），并有专属剧情与背景音乐切换。
- **Boss 必须可以打赢**：要算清楚玩家沿途能拿到的攻防道具、升级成长、商店补给，保证攻击大于 Boss 防御，且战后剩余血量大于 0。不能出现"地图能走到，但打不过"的情况。

**商店（商人）**
- 商人（N）出现在第 3、7、9、18 层，用金币购买：攻击强化（+5 攻击）、防御强化（+5 防御）、生命药剂（+300 生命）、黄钥匙。
- 价格随购买次数递增。中后期（第 9 层起）的补给点必须存在，让玩家在没有血瓶时仍有恢复手段。

**存档与读档**
- 自动存档：每次上下楼时更新（"自动存档"槽位）。
- 手动存档：3 个槽位，显示层数、等级、时间，可保存、读取、删除。
- 使用 `localStorage`，读写都做 try/catch，存储不可用时游戏仍能运行。
- **老存档修复**：存档保存的是每层的完整地图，地图改版后，读档时要检查每层的结构（墙、上楼梯、入口）。与当前数据不一致的层用最新地图重建，勇士放到该层入口；结构一致的层保留进度（已拿道具、已开门、已击败怪物）。

**图鉴**
- 遇到过的怪物、获得过的道具会被记录，未遇到的显示为"？？？"。

**按住连续移动**
- 键盘方向键或触屏方向键按住时连续移动（按下立即走一步，停顿后按固定间隔继续），撞墙、遇到怪物、弹出窗口时自动停止。

**难度**
- 提供**普通**与**困难**两档，默认普通。两档都必须能通关。
- 普通：标准数值。
- 困难：怪物生命 ×1.15，攻击不加成，金币不打折（靠更厚的血量拉开难度，而不是让怪物攻击过高导致无法通关）。
- **不要简单难度**。

**隐藏模式（无敌与跳转）**
- 默认不可见。在游戏中**连续点击人物 10 次**（两次点击间隔超过 1.5 秒则重新计数，点到第 5 次时提示"还需要 5 次"）即可解锁，弹出"隐藏模式已解锁"提示。
- 解锁后，设置面板中出现：
  - **无敌模式**开关（默认关闭）：开启后受到的伤害为 0，战斗预览仍按公式显示；屏幕右上角显示金色"无敌"标识。
  - **跳转楼层**：下拉选择第 1–20 层，点击"传送"，勇士出现在该层入口，属性与道具保留。跳转视为作弊，本局不计入隐藏结局。
  - **退出隐藏模式**按钮：关闭无敌，收起隐藏功能，清除解锁记录；想再用需要重新连续点击人物 10 次。
- 无敌状态写入存档；如果没有解锁隐藏模式，读取存档时无敌强制关闭（防止旧存档残留）。
- 解锁记录带版本号，旧版本留下的解锁记录自动失效。

### 七、技术与代码质量要求

1. **性能**：动画与逻辑分离，避免每帧创建大量对象；切换楼层时释放资源；定时器与事件监听在组件卸载时清理。
2. **可维护性**：核心逻辑（伤害计算、开门判断、战斗结算、战斗预览、地图寻路、存档修复）为纯函数，与 Vue 解耦，便于测试。
3. **自动化测试**（`node tests/run.js`，必须全部通过）：
   - 伤害公式与战斗结算，包括无法破防、Boss 双倍反击、难度修正。
   - 战斗预览：血量足够可战斗、血量不足标记为会死亡、无敌时损失为 0、无法破防不可战斗。
   - 钥匙与门：没有钥匙不能开门，有钥匙开门并消耗。
   - **每层地图尺寸、边界、楼梯数量**检查。
   - **每层可解性检查**：BFS 模拟钥匙与门，从入口能到达上楼梯（最后一层到达终极 Boss）。
   - **不能跳层检查**：除第 1 层外，不拿钥匙时上楼梯走不到。
   - **真实战斗通关模拟**：用真实的移动与战斗规则，写一个贪心玩家（拿道具、打能打且打完能活的怪、血量不足时去商店买药、开能开的门），在普通、困难两档下从第 1 层一路模拟到结局。两档都必须通关；如果卡住，必须修复数值或地图，而不是放宽测试。
   - 存档序列化往返一致；老存档修复（旧地图被重建，勇士放到入口）；结构一致的楼层保留进度。
   - 隐藏结局判定：收齐 3 枚碎片且未作弊时为隐藏结局；使用过无敌或跳转则不触发。
   - 跳转楼层：位置正确、记为作弊、超出范围被拒绝。
4. **不要留下 TODO 占位或空函数**。如有未完成的功能，在最终说明中明确列出。

### 八、开发顺序建议

1. 搭建 Vue 工程、渲染与输入，能显示可移动的勇士和地图。
2. 实现地图数据、门与钥匙、道具拾取。
3. 实现战斗与数值结算、战斗预览，跑通单元测试。
4. 实现楼层切换、存档（含老存档修复）、商店、图鉴。
5. 加入 Boss 战与剧情。
6. 加入隐藏模式（连续点击人物解锁、无敌、跳转楼层、退出）。
7. 视觉与音效打磨：素材（无条纹的地面与墙）、粒子、通关特效、字体、配色、音频（每层一首、标题音乐、手机手势解锁）。
8. 响应式：手机单屏布局；电脑端模拟器 + 介绍面板 + 二维码，一屏显示。禁止缩放。
9. 用浏览器（无头 Chrome）截图检查：手机尺寸与电脑尺寸各一套，确认没有滚动、没有横向溢出、卡片文字不重叠。
