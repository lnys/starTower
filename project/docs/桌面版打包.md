# 星穹塔桌面版

Vue 负责界面，`src/game/star/` 负责游戏规则，`electron/main.cjs` 负责桌面窗口、原生菜单、单实例、离线加载及权限隔离。开发和打包均加载本地 `dist/index.html`，不依赖开发服务器。渲染进程关闭 Node 权限，启用上下文隔离与沙箱。

## 运行与构建

```bash
npm install
npm run desktop        # 构建并启动桌面版
npm run desktop:test   # 检查界面、新游戏、图片与自动存档
npm test               # 包括完整通关路线回放
npm run dist:mac       # Intel + Apple 芯片通用版 DMG / ZIP
npm run dist:win       # Windows x64 安装程序 / 便携版
```

Mac 通用版支持 macOS 13 及以上，包含 x86_64 与 arm64 两种架构。产物位于 `release/`。Mac 安装时打开 DMG，将「星穹塔」拖入 Applications；也可以解压 ZIP 后运行应用。Windows 输出 x64 NSIS 安装版（文件名以 `-setup.exe` 结尾）和 portable 便携版（以 `-portable.exe` 结尾），Windows 实机验证另行执行。两种 Windows 版本均将存档写入用户数据目录，便携版的存档不会随 EXE 移动。

## 存档

Mac：`~/Library/Application Support/StarDomeTower/`。

Windows：`%APPDATA%\StarDomeTower\`。

应用名称和数据目录固定，更新或移动应用不会切换存档目录。桌面版与浏览器的存储空间独立，不会自动导入网页版进度。冒烟测试使用临时数据目录，不覆盖正式存档。

## 分发说明

当前为本地测试包，已做 ad-hoc 本地签名并校验，未配置 Apple Developer ID 签名或公证。`scripts/after-pack.cjs` 会在打包时重新签名，修复 Universal 合并后的签名失效问题。若 macOS 阻止打开，使用系统设置 → 隐私与安全性 → 仍要打开。正式公开分发前应配置开发者证书并完成公证。

桌面版阻止网络资源，使用系统中文字体；游戏图片和程序化音频均在本地。网页版本仍保留原有构建方式。
