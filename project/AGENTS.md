# 星穹塔维护约定

- 在同时包含游戏源码和 `skills/project/` 的工作区，每次修改源码、资源或项目文档后，在根目录运行 `python3 skills/sync-project.py <改动文件...>`，同步本次涉及的文件到 Skill 快照并更新 `skills/MANIFEST.sha256`。参数为相对项目根目录的路径。若删除或重命名项目文件，也要移除快照中的旧文件及清单条目。
- 同步后运行 `bash skills/verify.sh`。不要把依赖、构建产物、本地配置或不属于本次任务的本地改动复制进快照。若只改动 Skill 自己的入口或文档，不要把 `skills/` 再复制到快照里。
- 项目和 Skill 仓库各用 `README.md` 展示中文、`README.en.md` 展示英文，页首互相链接；以后更新说明、命令或链接时同时维护两个版本。
- 本地同步不意味着提交、推送或发布；这些操作按用户要求执行。
